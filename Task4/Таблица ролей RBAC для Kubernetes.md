# Таблица ролей 

| Роль                             | Права роли                                                                                                  | Группы пользователей                    |
|----------------------------------|-------------------------------------------------------------------------------------------------------------|-----------------------------------------|
| propdevelopment-namespace-admin  | Полный доступ к ресурсам в определенном namespace (включая секреты)                                         | Владельцы продуктов                     |
| propdevelopment-security-auditor | Право на чтение всех ресурсов, включая секреты, логи и конфигурации                                         | Специалист по ИБ, аудиторы безопасности |                                                                 
| propdevelopment-developer        | Право на чтение конфигураций приложений, просмотр логов в присвоенных namespace, создание тестовых ресурсов | Разработчики                            |                                                                  
| propdevelopment-viewer           | Право на чтение ресурсов только в присвоенных namespace, без доступа к секретам и логам                     | Менеджеры и бизнес-аналитики            |

# Скрипты для запуска:

1) Создание namespace для PropDevelopment
````shell
./create-namespaces.sh
````

2) Создание пользователей для PropDevelopment 
````shell
./create-users.sh
````

3) Применение RBAC ролей 
````shell
./apply-roles.sh
````

4) Применение bindings 
````shell
./apply-bindings.sh
````
